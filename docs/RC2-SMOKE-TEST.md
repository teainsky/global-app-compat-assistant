# RC2 真机冒烟测试清单

记录每项为 `PASS / FAIL / BLOCKED`，并保存对应截图。不得在测试过程中卸载、覆盖或修改现有 Google 组件。

前置条件：使用项目负责人发布密钥签名后的 `0.1.0-rc2` APK。`assembleRelease` 生成的 unsigned APK 只用于构建核验，不作为真机分发包。

## 通用检查

- [ ] RC2 APK 可安装、启动，不依赖 GMS 才能打开。
- [ ] 首屏只出现“开始检测”和“免费版说明”。
- [ ] 免费版说明包含免费、不 Root、不解锁 Bootloader、不修改 ROM、首版不支持 TikTok。
- [ ] 检测前后均没有账号、支付、广告、模拟计划、开发审计或内部调试入口。
- [ ] 技术字段默认折叠；普通结果没有 SHA、Catalog、Evidence、Decision 等术语。
- [ ] 未主动点击已验证配置入口时，没有组件下载或系统安装界面。

## Huawei Pura 70 Pro+ / HBN-AL80 / HarmonyOS 4.2

- [ ] 设备型号识别为 `HBN-AL80`，HarmonyOS 为 `4.2.x`，Android API 为 `31`。
- [ ] 能力标签包含“可检测”“可诊断”“已验证可配置”。
- [ ] 已正确安装官方两件套时，结果为“当前无需处理”。
- [ ] 页面不提示重装、覆盖、卸载或修复正确组件。
- [ ] 已验证设备配置区显示当前组件正确，不主动准备或下载文件。
- [ ] 三项自检可分别选择，全部为“是”时只显示自检通过，不改变全局验证状态。
- [ ] 展开技术详情后，Catalog 摘要、精确验证等级和组件比对状态与当前签名 Catalog 一致。

## Huawei Pura / HarmonyOS 6.1.0.135 + 卓易通

- [ ] HarmonyOS 识别进入 `HARMONY_NATIVE` / HarmonyOS 5+ 独立分支。
- [ ] 即使卓易通内可见 Google 组件，也不进入 HarmonyOS 1–4 microG 工作流。
- [ ] 能力仅展示“可检测”“可诊断”，不展示“已验证可配置”。
- [ ] Google 环境说明为现有 Android 兼容配置流程不适用，不写“永久不支持”。
- [ ] 页面没有准备环境、下载 Huawei `-hw` 两件套或安装入口。
- [ ] 自检可以记录现状，但不能解锁配置。
- [ ] 展开技术详情确认平台/ROM 分类正确，随后折叠并保存诊断截图。

## 退出条件

- 任一设备出现错误配置入口、后台下载、安装弹窗或系统分支误判，RC2 立即停止发布。
- 两台设备的必测项全部 PASS 后，才进入签名 Release APK 和 GitHub Release 的单独审批步骤。
